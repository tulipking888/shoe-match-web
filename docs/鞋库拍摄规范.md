# 鞋库拍摄规范

## 目的

为了提高鞋子图像匹配准确率，所有入库照片和查询照片建议遵循统一拍摄规范。

图像识别效果不仅取决于算法，也受到拍摄角度、光线、背景等因素影响。

------------------------------------------------------------------------

# 一、库存入库拍摄规范

## 1. 鞋子摆放

推荐：

-   鞋头朝向一致
-   鞋身完整展示
-   左右鞋不要重叠
-   不遮挡品牌标识和主要外观

示例：

    正确：
          👟
    完整展示鞋身

    错误：
    鞋子被遮挡
    只拍鞋底
    只拍局部

------------------------------------------------------------------------

## 2. 拍摄距离

建议：

-   鞋子占照片面积 60%～80%
-   不要距离过远
-   不要裁掉鞋尖或鞋跟

------------------------------------------------------------------------

## 3. 拍摄背景

推荐：

-   白色背景
-   灰色背景
-   单色背景

避免：

-   杂乱仓库环境
-   大量其他物品
-   花纹复杂背景

------------------------------------------------------------------------

## 4. 光线要求

推荐：

-   光线均匀
-   避免强烈反光
-   避免明显阴影

不要：

-   夜间弱光拍摄
-   直接对着强光源拍摄

------------------------------------------------------------------------

# 二、编号规范

建议每双鞋建立唯一编号。

例如：

    A001
    A002
    A003

如果同款不同颜色：

    A001-BLACK
    A001-WHITE
    A001-RED

避免：

-   多双鞋使用同一个编号
-   后期修改编号导致查找困难

------------------------------------------------------------------------

# 三、位置填写规范

推荐格式：

    仓库-区域-货架-层

例如：

    1号仓-A区-03排-05层

这样查询结果可以快速定位。

------------------------------------------------------------------------

# 四、查询拍摄建议

现场找鞋时：

尽量：

-   与库存照片保持类似角度
-   保证鞋子完整进入画面
-   避免手遮挡鞋面

如果第一次匹配不准确：

可以：

-   换角度重新拍摄
-   靠近鞋子拍摄
-   调整光线

------------------------------------------------------------------------

# 五、批量入库建议

第一次建立鞋库：

建议流程：

1.  按仓库区域分批录入
2.  每完成100～500双进行备份
3.  导出数据文件保存

避免一次性大量录入后数据丢失。

------------------------------------------------------------------------

# 六、未来升级方向

如果需要更高识别率，可以增加：

-   多角度库存照片
-   AI视觉模型
-   商品图片向量搜索
-   条码/二维码辅助定位
