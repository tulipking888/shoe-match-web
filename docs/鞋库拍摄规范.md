# 鞋库图片拍摄规范

## 1. 目的

本规范用于统一“样品入库图”和“现场查询实拍图”，降低背景、角度、遮挡、光线及构图差异对匹配结果的影响。

当前 V5 会综合鞋型、局部细节和颜色，并自动处理横竖方向；但算法无法恢复被裁掉或被遮挡的鞋头、鞋跟、鞋底和装饰细节。规范拍摄仍然是提高准确率最直接的办法。

## 2. 最重要的六条规则

每次拍摄都应满足：

1. 除约定的双鞋组合图外，一张图只拍一只鞋。
2. 拍鞋身侧面，摄像头尽量与鞋身侧面垂直。
3. 鞋头、鞋跟和鞋底必须完整，不得贴边或被裁掉。
4. 鞋子占画面约 70%～85%，四周保留少量背景。
5. 使用简单、无花纹、与鞋子颜色有反差的背景。
6. 光线均匀，避免强反光、过暗、严重阴影和运动模糊。

## 3. 样品入库图规范

### 3.1 推荐数量

最低要求：每个完整样品编号 1 张标准侧面图。

推荐要求：每个完整样品编号提供 3 张图。

三张图没有固定顺序，也没有优先级。可以是单鞋，也可以是双鞋；推荐让整组三张图尽量覆盖以下构图：

| 推荐构图 | 用途 |
| --- | --- |
| 单鞋外侧标准侧面 | 识别鞋型轮廓、鞋底曲线和主要装饰 |
| 双鞋组合 | 满足业务展示要求，并补充双鞋构图特征 |
| 单鞋前外侧约 30°～45° | 补充鞋头、鞋带、拉链和鞋面结构 |

如果经常从内侧拍查询图，可增加第 4 张内侧标准侧面图。

同一编号增加多张参考图通常比继续微调匹配权重更有效，因为系统可以直接学习该鞋在不同角度、距离和背景下的外观。V5 已支持同编号多条记录，查询时会自动合并。

### 3.2 Excel 录入多张样品图

推荐一个完整编号只占一行，分别把三张照片嵌入 `图片1`、`图片2`、`图片3`。三个字段完全等价，没有主次、角度或单双鞋限制。系统会把每张图片独立提取为一条特征记录，查询时再按相同完整编号合并。

示例：

| 样品编号 | 图片1 | 图片2 | 图片3 |
| --- | --- | --- | --- |
| `280573 burgundy` | 双鞋组合图 | 单鞋标准侧面图 | 单鞋前外侧 30°～45° 图 |

图片必须真正嵌入对应单元格，不要填写本地路径，也不要把三张照片拼成一张图片。旧版“同编号重复多行、每行一图”的Excel仍可导入，但不再作为推荐录入方式。

### 3.3 摆放与角度

- 每个图片字段都可以放单鞋或双鞋，系统不按字段位置设置权重。
- 同一编号的三张图应尽量使用不同构图，避免三张几乎完全相同。
- 鞋身长轴尽量接近水平。
- 摄像头对准鞋身中部，不要明显俯拍或仰拍。
- 标准侧面图应能清楚看到鞋头、鞋口、鞋跟、鞋底曲线和侧面装饰。
- 左右鞋都可使用，但同一批样品最好统一使用同一只脚和同一朝向。
- 双鞋可以自然组合，但至少要有一只鞋的鞋头、鞋跟、鞋底和主要外侧结构完整可见。
- 双鞋图不能作为该编号的唯一参考图。

### 3.4 画面占比与清晰度

- 鞋子占画面宽度约 70%～85%。
- 鞋头和鞋跟距离画面边缘至少保留约 5% 空间。
- 建议图片长边不低于 1280 像素。
- 推荐统一使用不透明浅灰背景的 JPG，sRGB 色彩，质量约 90%；不使用透明背景。
- 使用手机后置摄像头的 1× 镜头。
- 不使用数码变焦，不拍屏幕截图，不给图片添加滤镜或美颜。
- 对焦点放在鞋面中部，拍完检查鞋带、缝线和纹理是否清楚。

### 3.5 背景与光线

推荐背景：

- 哑光浅灰背景；
- 米白或纯色背景；
- 与鞋身主色有明显反差的地面或背景板。

避免背景：

- 花纹地毯、货架、包装箱和大量其他鞋子；
- 镜面、强反光瓷砖；
- 与鞋身颜色非常接近的背景；
- 明显地砖线穿过鞋身轮廓。

推荐使用柔和、均匀的环境光。浅色鞋避免过曝，漆皮和金属装饰避免闪光灯直射。

## 4. 现场查询实拍图规范

### 4.1 标准查询姿势

1. 将鞋子单独放置，或只用手托住鞋底边缘。
2. 把手机转到鞋身侧面，与鞋身保持大致平行。
3. 距离约 50～80 厘米，以鞋子占画面 70%～85% 为准。
4. 确认鞋头、鞋跟、鞋底全部在画面内。
5. 点击对焦，保持手机稳定后拍摄。

手持拍摄时，手尽量只接触鞋底或后跟下方，遮挡面积不要超过鞋身的 10%。

### 4.2 查询失败时的补拍顺序

如果第一名明显不对，按以下顺序补拍，不要连续提交几张几乎相同的错误照片：

1. 改为完整外侧面，消除俯拍角度。
2. 靠近一些，让鞋子占满约 80% 画面。
3. 换到无杂物、与鞋色有反差的背景。
4. 调整光线，避免鞋面过暗或反光发白。
5. 再拍一张前外侧 30°～45° 图，对照两次 Top 5。

如果两个结果都把同一数字鞋型排在前列、仅颜色不同，应重点检查现场光线、样品图白平衡以及颜色名称是否录入正确。

## 5. 编号与配色规范

当前数据适合使用“数字鞋型编号 + 标准颜色名”的格式，例如：

```text
280573 black
280573 l.blue
280573 burgundy
280525 taupe
```

建议：

- 同一鞋型的数字部分必须完全一致。
- 不混用 `light blue`、`l.blue`、`ltblue` 等多套写法。
- 一个完整编号只对应一个明确配色。
- 同一完整编号的多角度照片必须使用完全相同的编号文本。
- 不要在编号前增加临时批次文字，否则可能影响鞋型分组。

## 6. 拍摄验收清单

入库或查询前快速检查：

- [ ] 三张图整体覆盖了有差异的角度或单双鞋构图
- [ ] 鞋头、鞋跟和鞋底完整
- [ ] 鞋子占画面 70%～85%
- [ ] 以标准侧面为主，没有明显俯拍
- [ ] 鞋面纹理、拉链和饰条清晰
- [ ] 背景简单，并且与鞋身有反差
- [ ] 无严重反光、阴影、模糊和滤镜
- [ ] 手没有遮挡关键结构

不符合前三项时，建议直接重拍，不要依赖算法补救。
