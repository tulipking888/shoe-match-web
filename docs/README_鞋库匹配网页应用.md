# 鞋库匹配网页应用

一个基于浏览器端运行的手机拍照找鞋系统。

## 功能介绍

本项目实现：

-   手机拍照上传鞋子照片
-   建立本地鞋库
-   自动生成鞋子图像指纹
-   图片相似度匹配
-   返回 Top 5 相似鞋子
-   显示鞋子编号、存放位置、库存照片

适用于：

-   仓库找鞋
-   鞋店库存管理
-   小型仓储快速定位

------------------------------------------------------------------------

## 使用方式

本项目无需服务器。

部署后，手机浏览器打开网页即可使用。

推荐：

-   Chrome（Android）
-   Safari（iPhone）

也可以添加到手机桌面，作为类似 App 的应用使用。

## 核心流程

### 1. 鞋子入库

标准拍摄一张库存照片：

    拍照
     ↓
    输入编号
     ↓
    输入存放位置
     ↓
    生成图像指纹
     ↓
    保存到本地数据库

例如：

    编号：
    A001

    位置：
    1号仓-A区-3排

------------------------------------------------------------------------

### 2. 查询鞋子

现场拍摄鞋子：

    手机拍照
     ↓
    计算查询指纹
     ↓
    与已有鞋库比较
     ↓
    返回Top 5结果

结果包含：

-   鞋子编号
-   存放位置
-   库存照片
-   相似度

## 数据存储说明

当前版本采用浏览器本地存储：

-   IndexedDB
-   不需要服务器
-   数据不会上传到网站
-   断网情况下也可以使用

注意：

不同手机之间不会自动同步。

建议定期：

    数据管理
     ↓
    导出备份

保存备份文件。
