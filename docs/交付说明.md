# 鞋库拍照匹配系统交付说明

## 1. 交付信息

- 交付版本：`V5.2.0`
- 线上地址：<https://tulipking888.github.io/shoe-match-web/>
- 部署方式：GitHub Pages 静态部署
- 运行方式：纯浏览器本地运行，无业务服务器
- 数据位置：当前设备、当前浏览器的 IndexedDB

样品图片、业务字段和查询照片不会上传到业务服务器。不同设备和不同浏览器之间不会自动同步数据。

## 2. 推荐初始化流程

### 2.1 电脑建立主鞋库

1. 使用 Chrome 或 Edge 打开线上地址，确认页面底部显示 `V5.2.0`。
2. 进入“批量与管理”，导入最新版完整 Excel。
3. 等待导入完成，检查成功数、失败数和样品总数。
4. 使用已知测试照片验证正确编号能进入 Top 1。
5. 点击“导出样品库数据包”，保存生成的 JSON 文件。

### 2.2 手机初始化

1. 手机首次联网打开网页，等待网页和 AI 模型完成缓存。
2. 确认页面底部显示 `V5.2.0`。
3. 进入“批量与管理”，选择“导入样品库数据包”。
4. 选择电脑导出的 JSON 文件，检查导入后的样品总数。
5. 使用一张已知照片完成查询验收。

手机不需要重新导入 Excel。样品库数据包已经包含 AI 特征，导入速度更快，也能避免手机长时间计算时因锁屏或切换应用而中断。

## 3. 后续补图与更新

推荐始终把完整 Excel 作为业务主数据：

1. 在电脑的主 Excel 中补充或替换样品图。
2. 电脑网页删除旧样品批次，再导入最新版完整 Excel。
3. 完成查询验证后，重新导出样品库数据包。
4. 手机删除旧鞋库，再导入新的数据包。

不要在同一设备反复追加整份完整 Excel 或完整数据包，否则会产生重复样品特征。

## 4. 批次与历史记录

- “删除本批”：删除该批次的样品数据，但保留“已删除”历史卡片。
- “删除记录”：仅出现在已删除卡片上，用于永久清除该条历史记录。
- “清空全部样品”：删除当前浏览器的全部样品，但保留批次历史；操作需要输入 `DELETE`。

删除数据或更换设备前，建议先保存最新版 Excel 和样品库数据包。

## 5. 交付验收清单

- [ ] 页面版本为 `V5.2.0`
- [ ] 最新完整 Excel 导入完成且失败项已核对
- [ ] 电脑端已导出样品库数据包
- [ ] 手机端数据包导入后的样品数与电脑一致
- [ ] 已知测试图片的正确编号进入 Top 1
- [ ] 首次联网加载后，断网状态仍能打开网页并完成查询
- [ ] 最新 Excel 和样品库数据包已保存在安全位置

## 6. 使用边界

- 系统返回的是视觉相似度排序，不是统计概率。
- 同鞋型、同结构、相近颜色的鞋仍可能需要结合 Top 3 人工确认。
- 拍摄时应保证鞋头、鞋跟和鞋底完整，减少遮挡、模糊和强反光。
- 清理浏览器网站数据、卸载浏览器或更换浏览器会丢失本机鞋库，需要重新导入数据包。

详细操作参见[手机操作流程](./手机操作流程.md)，拍摄要求参见[鞋库图片拍摄规范](./鞋库拍摄规范.md)，实现与升级路线参见[技术方案总结](./技术方案总结.md)。
