# 鞋库匹配系统设计说明

## 一、项目定位

鞋库匹配系统是一套基于浏览器运行的轻量视觉检索工具。

目标：

通过手机拍摄鞋子照片，快速找到库存编号和存放位置。

------------------------------------------------------------------------

# 二、整体架构

当前版本：

    手机浏览器

        ↓

    GitHub Pages 静态网页

        ↓

    JavaScript 图像处理算法

        ↓

    IndexedDB 本地数据库

        ↓

    返回 Top 5 匹配结果

------------------------------------------------------------------------

## 1. 前端页面

## 2. 图像特征计算

## 3. 本地数据库

采用：

    IndexedDB

保存：

-   鞋子编号
-   存放位置
-   图片缩略图
-   图像指纹

优势：

-   无需服务器
-   数据保存在设备本地
-   离线可使用

------------------------------------------------------------------------

# 四、为什么当前版本不需要服务器

传统系统：

    手机

    ↓

    服务器

    ↓

    数据库

需要：

-   云服务器
-   数据库
-   后端接口
-   运维成本

当前方案：

    手机

    ↓

    浏览器本地数据库

适合：

-   小规模仓库
-   Demo验证
-   内部工具测试

------------------------------------------------------------------------

# 五、识别算法说明

当前采用轻量方案：

## 感知哈希

用于判断整体图像相似度。

## 颜色特征

用于辅助区分：

-   不同颜色鞋款
-   外观差异

## 边缘特征

用于判断：

-   鞋型轮廓
-   外形结构

最终：

    多个特征综合评分

    ↓

    相似度排序

    ↓

    Top 5结果

------------------------------------------------------------------------

# 六、当前版本限制

## 数据共享

当前数据属于单设备。

例如：

手机A录入：

    A001

手机B不会自动看到。

------------------------------------------------------------------------
