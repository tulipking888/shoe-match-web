# 项目文档

当前文档均以 V5.2.0 为基准。

- [交付说明](./交付说明.md)：上线验收、电脑建库、手机迁移和后续维护流程。
- [鞋库图片拍摄规范](./鞋库拍摄规范.md)：样品图、查询实拍图、多参考图和编号规范。
- [手机操作流程](./手机操作流程.md)：首次导入、日常查询、补拍、备份、恢复和离线使用。
- [技术方案总结](./技术方案总结.md)：V5 架构、特征、排序逻辑、限制和准确率提升路线。

建议使用顺序：

1. 项目负责人先阅读交付说明，完成上线验收和设备初始化。
2. 管理员阅读技术方案，确定数据维护和升级方式。
3. 样品拍摄人员按拍摄规范制作 Excel 图片。
4. 现场使用人员按手机操作流程进行查询和补拍。

项目根目录的 [README](../README.md) 仅保留部署与功能概览，业务执行细节以本目录文档为准。
