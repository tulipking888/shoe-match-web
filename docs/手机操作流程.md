# 鞋库匹配网页手机操作流程

## 1. 使用前准备

- Android 推荐最新版 Chrome。
- iPhone 推荐最新版 Safari。
- 系统地址：<https://tulipking888.github.io/shoe-match-web/>
- 首次打开必须联网，让网页、运行库和本地 AI 模型完成加载与缓存。
- 页面底部应显示当前版本；交付版本需要显示 `V5.2.0`。

样品库保存在当前手机的当前浏览器中。同一网址换浏览器打开、清理网站数据或更换手机，都不会自动带上原数据库。

## 2. 首次建立样品库

### 2.1 准备 Excel

使用项目提供的样品导入模板，支持字段：

- 样品编号；
- 样品寄出时间；
- 客户编号；
- 订单编号；
- 特别要求；
- 图片1、图片2、图片3（Excel 内嵌图片）。

图片必须真正嵌入工作表，不能只填写本地文件路径或网络链接。

推荐每个完整编号只占一行，在 `图片1`、`图片2`、`图片3` 中嵌入三张有差异的参考图。三个字段完全等价，没有固定角度、单双鞋要求或匹配优先级；旧版同编号重复多行的文件仍兼容。推荐拍法见[鞋库图片拍摄规范](./鞋库拍摄规范.md)。

### 2.2 批量导入

1. 打开网页，进入“批量与管理”。
2. 在“Excel 批量导入”中点击“选择 Excel 文件”。
3. 选择准备好的 `.xlsx` 文件。
4. 点击“开始导入”。
5. 保持网页在前台，不要锁屏、刷新或切换到其他耗内存应用。
6. 等待进度达到总数，并确认失败数为 0。
7. 检查页面顶部样品数量是否正确。

首次导入会逐张在本机计算 AI 特征。Excel 较大时需要几分钟，这是正常现象。

### 2.3 V4 升级到 V5

如果页面提示“旧版数据需重新导入”：

1. 确认手中仍有原始 Excel 或已导出的 V5 兼容备份。
2. 进入“批量与管理”。
3. 点击“清空全部样品”。
4. 按提示输入 `DELETE`。
5. 重新导入原始 Excel。

不要把 V4 的旧特征备份当作 V5 数据继续使用。

## 3. 日常拍照查询

1. 进入“图片识别”。
2. 现场拍摄时点击“手机拍照识别”；已有照片时点击“从相册或文件选择”。
3. 按标准侧面拍摄，保证鞋头、鞋跟和鞋底完整。
4. 选择照片后等待本机 AI 完成比对。
5. 查看 Top 5，优先核对第一名的编号、缩略图和颜色。
6. 点击结果缩略图可查看大图。

电脑实测 731 条数据单次查询约 2.3～2.5 秒；手机耗时会因芯片和内存不同而变化。

## 4. 第一名不正确时

先不要立刻判断数据库错误，按以下顺序处理：

1. 查看正确鞋型是否已经进入 Top 3 或 Top 5。
2. 按拍摄规范补拍完整外侧面。
3. 避免俯拍，让摄像头与鞋身侧面平行。
4. 换到简单且与鞋色有反差的背景。
5. 确保手没有遮挡鞋头、鞋跟、拉链或饰条。
6. 如果鞋型正确但颜色错误，在光线更均匀的环境重拍。
7. 检查该完整配色编号是否已经导入正确样品图。

如果某个编号经常只能排到第 2～3，先检查三张规范棚拍图是否齐全，再补充差异明显的后斜侧图，并在对应行增加新的图片字段后重新导入。

## 5. 单条样品入库

临时增加少量样品时：

1. 进入“单条入库”。
2. 填写完整样品编号。
3. 拍摄或选择符合规范的样品图。
4. 点击“计算 AI 特征并保存”。
5. 等待保存成功并确认顶部数量增加。

同一完整编号允许保存多张图片，查询时会自动合并。

大量样品仍建议维护在 Excel 中统一导入，便于统一维护和重建数据库。

## 6. 导入批次管理

“批量与管理”会记录每次 Excel 导入批次，包括：

- 文件名和文件大小；
- 导入时间；
- 总数、成功数和失败数；
- 当前仍保留的记录数；
- 失败报告。

第一次点击“删除本批”只删除该批次导入的样品，其他批次不受影响；历史卡片会变成“已删除”。如果历史记录越来越多，可在“已删除”卡片上点击“删除记录”永久清除该卡片。删除记录无法恢复，但不会再次影响样品数据。

重复导入相同文件时系统会提醒。确认内容确实需要作为新批次保留后，再选择继续。

## 7. 样品库数据包与手机迁移

电脑端已经完成 Excel 导入时，推荐导出样品库数据包再传到手机。数据包包含业务字段、缩略图和已经计算好的 AI 特征，因此手机无需重新导入和计算整份 Excel。

### 7.1 电脑导出样品库数据包

1. 进入“批量与管理”。
2. 点击“导出样品库数据包”。
3. 将生成的 JSON 文件保存到安全位置。

建议在以下时间备份：

- 完成一次大批量导入后；
- 删除批次或清空数据前；
- 浏览器升级、清理缓存或更换手机前；
- 需要把电脑鞋库迁移到一台或多台手机时。

### 7.2 手机导入样品库数据包

1. 手机联网打开网页，等待网页和 AI 模型首次加载完成，并确认显示 `V5.2.0`。
2. 进入“批量与管理”。
3. 如果手机里已有旧鞋库，先删除旧批次或清空全部样品，避免重复。
4. 点击“导入样品库数据包”。
5. 选择电脑导出的 JSON 文件。
6. 等待页面提示“无需重新计算 AI 特征”。
7. 检查样品总数，并用已知照片查询一次。

这种方式比手机重新导入 Excel 更方便、更快，也更不容易因为锁屏或切换应用导致长时间特征计算中断。Excel 仍应作为业务主数据长期保存，用于以后补图和重建鞋库。

如果数据包使用的 AI 特征版本与当前网页不兼容，系统会拒绝导入。此时应使用当前网页重新导出数据包，或使用原始 Excel 重建。

## 8. 离线使用

首次加载模型和导入样品时需要保持网络与页面稳定。完成网页资源缓存后，日常查询可以在无业务服务器的情况下本机运行。

建议在正式离线使用前做一次检查：

1. 联网打开网页并等待模型加载完成。
2. 成功查询一张已知样品。
3. 关闭网络后重新打开网页。
4. 再查询同一张图片，确认可用。

不同浏览器对离线缓存和后台页面的管理策略不同，因此不要只保留浏览器数据库，仍需保存 Excel 和样品库数据包。

## 9. 添加到手机桌面

Android Chrome：

1. 打开系统网址。
2. 点击右上角菜单。
3. 选择“添加到主屏幕”或“安装应用”。

iPhone Safari：

1. 打开系统网址。
2. 点击分享按钮。
3. 选择“添加到主屏幕”。

桌面入口仍然使用同一浏览器数据。删除桌面图标一般不会等于删除数据库，但清理浏览器网站数据会删除样品库。
