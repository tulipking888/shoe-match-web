# 鞋库拍照匹配（纯前端版）

功能：
- 手机拍照或选择图片入库
- 自动提取 256 位感知哈希、RGB 颜色直方图、边缘方向特征
- IndexedDB 本机数据库
- 查询时逐条计算相似度并返回 Top 5
- 库存编号、位置、库存照展示
- JSON 备份导出、导入、删除与清空
- PWA 离线缓存

## 使用方法

### 推荐：静态托管
将整个目录上传到 GitHub Pages、Cloudflare Pages、Netlify、OSS 静态网站等。它们只负责分发静态文件，不需要业务服务器或数据库。

### 局域网测试
在目录中运行：

```bash
python -m http.server 8080
```

电脑访问 `http://localhost:8080`；同一局域网手机访问 `http://电脑局域网IP:8080`。

注意：部分手机浏览器只有 HTTPS 或 localhost 才允许 PWA 安装；拍照文件选择通常仍可使用。

## 重要限制

当前版本是完全离线、零模型依赖的轻量方案。它适合“库存照和查询照角度相近、背景较干净”的场景。若查询照片角度、光线、遮挡差异很大，建议升级为浏览器端深度学习特征（MobileNet/CLIP/专门训练的鞋类模型）。

5000 条记录可以运行，但库存缩略图会占用浏览器存储空间。建议定期导出备份，并在目标手机上先用 500、2000、5000 条分阶段压测。
